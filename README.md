# 💰 Expense Tracker (Python)

A Python-based command-line application to manage daily expenses efficiently.
This project allows users to add, view, filter, and delete expenses with persistent data storage using JSON.

---

## 🚀 Features

* ➕ Add new expenses with amount and category
* 📋 View all recorded expenses
* 🔍 Filter expenses by category
* 💰 Calculate total expenses
* 🗑️ Delete specific expenses
* 💾 Data persistence using JSON file storage
* ⚠️ Input validation for better reliability

---

## 🛠️ Technologies Used

* Python
* JSON (for data storage)

---

## ▶️ How to Run

1. Make sure Python is installed
2. Clone or download this repository
3. Open terminal in project folder
4. Run the program:

```bash
python expense_tracker.py
```
